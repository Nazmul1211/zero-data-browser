⚠️ Why does this feel slower?

When JavaScript is disabled, modern websites cannot execute the code they need to fetch data, render content, or respond to your clicks. Pages appear blank or stuck — this is not a network speed issue; it's the browser doing its job by blocking all scripting. Use this mode only for reading static pages or when maximum threat protection is required.

How it Works

Aura isn't just a browser; it's a hardened Electron shell designed specifically for zero-data retention. Here is what happens when you launch a session:


  • Ephemeral Partitions: A temporary partition is generated dynamically — destroyed on quit.
  • WebRTC Lockdown: WebRTC is fully disabled at both the Chromium and JavaScript level.
  • Strict HTTPS Upgrade: Unsecured HTTP requests are forcefully upgraded or dropped.
  • Header Sanitization: Accept-Language, Sec-CH-UA client hints, and Referer headers are stripped or spoofed on every request.
  • Permissions-Policy Injection: Every response gets a Permissions-Policy header blocking camera, mic, geo, battery, and more.
  • 20+ Fingerprint Shields: Defensive scripts spoof Canvas, Audio, Screen, Font, Timezone, and Hardware APIs.
  • Content Security Policy: Strict CSP on the browser chrome prevents injection attacks.

Launch Aura Browser

1 Install Tor (One-time Setup)

Aura uses Tor to hide your IP. It automatically manages the connection, but you must have the Tor binary installed on your Mac. Run this once:

brew install tor

2 Launch the Browser

Aura will automatically detect your Tor installation, spin up a secure proxy tunnel, and tear it down when you quit the browser!

npm start

Or compile the standalone macOS Application using our build script:

npm run dist
